8 integer points, r² = 10,240. The only optimal 4-set is {p0, p2, p4, p6} (blue).

From every blue point, the first far point in the hull order p0 → p1 → … → p7 is white — and each white point is too close to another blue point (dashed).

So a search that always extends the same way, or starts from a point and its first far neighbour, fails from every start.

The paper’s two-sided search succeeds here. A proof of Claim 2 must therefore use both directions.

This 8-point set is our key example; every number can be checked by hand from the distance table in our report. Only one 4-subset is r-far: the four blue points. If you start at a blue point and step counter-clockwise, the first point at distance at least r is the white one next to it, and that white point is too close to the opposite blue point. So every one-directional greedy run fails. The original algorithm extends in both directions and does succeed here. What we learn: Claim 2 cannot be proved by a one-sided argument; both directions are essential.
