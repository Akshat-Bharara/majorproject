The near-linear bound shows in practice. One million points take about six and a half seconds; each tenfold increase in n costs about fourteen times more time, slope 1.15 on a log-log plot. For contrast, the general cubic DP needs up to 16 seconds for only 400 points. A technical note: integer coordinates up to 2^29 cannot hold a million points on a convex unimodal curve, so for the two largest sizes we use a bigger circle with 128-bit squared distances; the code is the same template.
