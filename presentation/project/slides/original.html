THE ORIGINAL PAPER

Three results in Singireddy, Basappa and Mitchell

RESULT 1 · SECTION 3

Bounded search tree

Grow a solution along the boundary in both directions, branching at each step.

O(2^k n² log² n)

Fixed-parameter tractable in k.

RESULT 2 · SECTION 4

Delaunay dynamic program

The optimal set’s Delaunay triangulation is built triangle by triangle.

O(n⁴ k²)

Exact for every k.

RESULT 3 · SECTION 5

Approximation for k = 3

Uses only the four extreme points and a few binary searches.

O(log n)

Ratio 1/(2√2) ≈ 0.354.

Our project: result 2 → a faster DP (Part 1) · results 1–3 → re-implemented and verified (Part 2) · result 1 → exact without branching for a special class (Part 3).

[Name 1] · Part 1

The original paper has three results. One: a bounded search tree that places disks along the boundary, branching left or right; this gives an FPT algorithm, exponential only in k. Two: a dynamic program over Delaunay triangulations, exact for any k, in O(n^4 k^2). Three: a very fast approximation for k = 3. The bottom line maps each result to the part of our talk that improves or examines it.
