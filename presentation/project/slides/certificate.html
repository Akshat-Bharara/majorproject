KEY TOOL

A Delaunay certificate for “far apart”

THEOREM (DELAUNAY CERTIFICATE)

A set S in convex position has all pairwise distances ≥ r if and only if S has a triangulation in which (a) every edge has length ≥ r and (b) every diagonal is locally Delaunay.

WHY IT HOLDS

Locally Delaunay everywhere ⇒ the triangulation is Delaunay. In a Delaunay triangulation of a convex set, the closest pair is always an edge. Short, rigorous proof.

WHY IT HELPS

Condition (a) looks at one edge, condition (b) at two neighbouring triangles. Both are local, so a dynamic program over chords can check them.

EXACT ARITHMETIC

“Locally Delaunay” is one in-circle test: a 3×3 determinant on integers that fits in 128 bits. No floating point anywhere.

The original DP also uses Delaunay triangulations; this theorem states precisely why that is correct. A set is r-far exactly when it has a triangulation with long edges whose diagonals are all locally Delaunay. Proof idea: local Delaunay everywhere implies global Delaunay (a classical lemma), and in a Delaunay triangulation of a convex set the closest pair is an edge (we prove it with an angle argument). Because both conditions are local, a DP can glue triangles one at a time and only check one edge or one pair of triangles per step.
