FINDING 2

The FPT algorithm rests on Claim 2

1

Start anywhere

Put the first disk on a vertex v. Both ends of the solution start at v.

2

Grow one end

Walk clockwise or counter-clockwise from that end; take the first vertex at distance ≥ 2r from every chosen centre.

3

Branch on the side

Two choices per step: at most 2^k paths per start vertex, n start vertices.

CLAIM 2 (PAPER)

If k disks fit, some start vertex has a path that places all k.

The paper’s proof is a picture argument (a Delaunay triangle of three centres, then “the boundary would self-intersect”). It does not say which vertices block which, so it is not a complete proof.

[Name 2] · Part 2

The FPT algorithm works like this: put a disk on a vertex, then repeatedly extend one of the two ends of the chain of disks, always taking the first vertex that is far enough from everything placed so far. Branch on which end to extend, so 2^k paths per start. Correctness depends on Claim 2: if a solution exists, some start and some sequence of left/right choices finds one. The proof in the paper argues from a figure with three centres and says the boundary would have to self-intersect, but it does not make that argument precise. So we tested the claim as hard as we could.
