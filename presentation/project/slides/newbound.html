NEW BOUNDS FOR THIS SUBPROBLEM

From O(n⁴k²) to O(n log² n)

TaskOriginal paperOurs
Decision, arc propertyO(2^k n² log n)O(n²)
Decision, unimodalO(2^k n² log n)O(n log n)
Optimisation, unimodalO(2^k n² log² n) or O(n⁴k²)O(n log² n) expected

HOW

Binary search finds each a(q) on a unimodal row. Each row splits at its peak into two sorted lists; a randomised binary search over these 2n lists never builds the n² distances.

HONEST SCOPE

For points exactly on a circle, O(n) was already known (Akagi et al.). Ours covers every unimodal set and needs no special geometry.

[Name 3] · Part 3

This is the subproblem with a better bound. For unimodal inputs, the first far point a(q) is found by binary search on each distance row. Following a chain of k steps is done with repeated squaring in O(n log k). For the optimisation we cannot even afford to list all n² distances, so we treat each row as two sorted lists split at its peak and pick a random candidate pivot each round; the expected number of rounds is logarithmic. Total: expected O(n log² n), versus O(2^k n² log² n) or O(n^4 k^2) in the original paper. To be fair: for points exactly on a circle a linear-time algorithm already existed; our result covers the whole unimodal class, which includes rounded and perturbed circles.
