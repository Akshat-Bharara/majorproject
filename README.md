# majorproject

k-dispersion solvers.

* Repository root: exact general-dimension solver via clique enumeration and matrix products (`main.cpp`, `dispersion.cpp`, `clique.cpp`, `matrix.cpp`).
* `convex/`: exact algorithms, experiments and data for points in convex position (see `convex/README.md`).
* `arc/`: near-linear exact algorithm for point sets with the arc property / unimodal sets (see `arc/NOTES.md`).
* `paper/`: the paper (`paper.tex`, `paper.pdf`).
